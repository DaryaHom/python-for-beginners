# Трекер подписок

Веб-приложение для учёта подписок и регулярных платежей.
Помогает пользователю осознать реальные расходы, которые накапливаются из подписок "по цене кофе", и проанализировать траты за выбранный период.

## Возможности
- добавление, редактирование и удаление подписок
- указание стоимости (общей или ежедневной), периода действия, категории и комментария
- хранение данных в PostgreSQL
- просмотр списка подписок
- аналитика расходов за выбранный период
- визуализация структуры расходов по категориям

## Стек технологий
- Python
- web-интерфейс на Flask
- PostgreSQL
- psycopg2
- pandas
- matplotlib
- HTML (Jinja2 templates)

## Аналитика
Приложение позволяет:
- посчитать общую сумму расходов за период
- построить круговую диаграмму расходов по категориям
- визуализировать финансовые привычки пользователя

Период анализа задаётся пользователем через интерфейс.

## Установка и запуск 
1. Установить зависимости из директории проекта `12-final_certification`:
```sh
pip install -r requirements.txt
```
2. Запустить PostgreSQL из директории `12-final_certification/deploy`:
```sh
make up-db
```
3. Накатить миграцию БД из директории `12-final_certification/deploy`:
```sh
make up-db
```
4. Запустить приложение из директории проекта `12-final_certification`
```sh
python main.py
```
5. Открыть в браузере. Порт по умолчанию - 8081:
```sh
http://127.0.0.1:8081
```
6. Остановить БД после завершения работы - из директории `12-final_certification/deploy`:
```sh
make down-db
```
