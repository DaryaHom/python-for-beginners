# Финансовый планер

## Описание проекта
Настольное Python-приложение для учета доходов и расходов с анализом и визуализацией данных

## Функционал
- Добавление дохода или расхода;
- Хранение данных - в CSV;
- Анализ расходов;
- Визуализация данных;
- GUI Tk.

## Запуск
```
pip install -r requirements.txt
python main.app
```
